# Power change force

This entry appears directly after Power change dynamics. It uses the same initial conditions and automatic throttle procedure: hold the configured starting throttle for at least five seconds, step to 100%, and record at least 15 seconds after measured full power.

The CSV records read-only pitch controller position and force. The PDF uses the existing report layout and selects the pitch force graph by default when BRUNNER measurements are present. The stated force tolerance requires approved aircraft reference data for an actual comparison.
