# 2.c.(2a)-force Flap change force (Retraction)

Uses the same automatic flap sequence as 2.c.(2a): initialize at Index 1, record a measured five-second baseline, command Index 0, and continue for at least fifteen seconds after flap movement ends.

All telemetry and controller channels are recorded. Pitch controller position and force are selected in the PDF by default. An approved aircraft reference is required for a force-tolerance comparison.
